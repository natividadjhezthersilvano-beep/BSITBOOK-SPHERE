Overview

HyperText Markup Language (HTML) is the standard markup language used to create and organize the content of webpages. It provides structure and meaning to information displayed in a web browser.

HTML allows developers to organize text, headings, paragraphs, images, hyperlinks, lists, and other webpage elements. It uses tags and attributes to describe how different parts of a webpage should be interpreted by a browser.

Modern websites use HTML together with Cascading Style Sheets (CSS) and JavaScript. HTML provides the structure, CSS controls the presentation and appearance, and JavaScript adds interactive behavior.

How the Web Works

When a user wants to visit a website, they enter a URL (Uniform Resource Locator) into a web browser. The browser communicates with a web server to request the webpage.

Client-Server Architecture

The Web uses a client-server architecture. This system involves two main types of computers:

  • Client: The computer or application that requests information. A web browser such as Chrome or Firefox acts as a web client.
  • Server: The computer that waits for requests and provides the requested webpages or resources.

The client communicates with the web server using HTTP (HyperText Transfer Protocol). The server receives the request and sends the requested resource back to the browser.

How a Webpage Is Requested

  1. The user enters a website URL into a browser.
  2. The browser sends an HTTP request to the web server.
  3. The web server receives and processes the request.
  4. The server returns the requested webpage or resource.
  5. The browser interprets the received files and displays the webpage.

Common Resources Sent Through HTTP

  • HTML files: Contain webpage content and semantic information.
  • CSS files: Contain formatting and styling instructions for webpages.
  • Image files: Include image formats such as JPEG, PNG, and GIF.

Functions of a Web Browser

  • Communicates with web servers using HTTP.
  • Reads HTML and CSS files to display webpages.
  • Displays images and other supported resources.
  • Uses JavaScript to execute client-side programs.

Introduction to HTML

HTML stands for HyperText Markup Language. It is the language used to define the structure and content of a webpage. Understanding each word helps explain its purpose.

HyperText

Hypertext refers to text or information that contains links connecting one resource to another. Unlike a traditional book, where pages usually follow a fixed order, hypertext allows users to move between related information through hyperlinks.

The World Wide Web combines hypertext with the Internet. It allows users to access connected information across different websites.

Hypermedia extends this idea by allowing links to connect not only text but also other media such as images, audio, and videos.

Markup

Markup refers to adding instructions or labels to a document to describe how its content should be organized or interpreted. In HTML, these instructions are written using tags.

Language

HTML is considered a markup language because it follows specific syntax rules and uses a defined collection of tags, elements, and attributes.

HTML takes ordinary text and adds markup information so that a web browser can understand and display the content correctly.

HTML Tags and Elements

HTML uses tags to identify and organize different types of content. Tags are written using angle brackets: < and >.

HTML Tags

A tag is a markup instruction that tells the browser how a particular piece of content should be interpreted. Most HTML elements use an opening tag and a closing tag.

For example:

<b>Hello World</b>
<i>Welcome to HTML</i>

The <b> tag represents bold text, while the <i> tag represents italic text.

Opening and Closing Tags

  • Opening tag: Marks where an element begins. Example: <p>.
  • Closing tag: Marks where an element ends. Example: </p>.

HTML Elements

An HTML element consists of the opening tag, its content, and the closing tag. An element acts like a container for the information placed inside it. 

<p>This is a paragraph.</p>

In this example, the complete paragraph markup is an HTML element. The opening tag identifies the beginning, the text is the content, and the closing tag ends it.

HTML Attributes

Attributes provide additional information about HTML elements. They are written inside the opening tag and usually consist of an attribute name and a value.

For example, the anchor tag <a> creates a hyperlink. However, it needs an href attribute to identify the destination of the link. 

<a href="https://www.example.com">
    Visit Example
</a>

In this example, href is the attribute name, and https://www.example.com is its value. The text "Visit Example" becomes the clickable link.

Common HTML Attributes

  • href: Specifies the destination of a hyperlink.
  • src: Specifies the location of an image or other embedded resource.
  • alt: Provides alternative text describing an image.
  • id: Identifies a specific element.
  • class: Assigns a class name to one or more elements.
  • title: Provides additional information about an element.

Attribute order generally does not change the meaning of an element. Attribute values should be placed inside quotation marks for clear and consistent HTML.

Common HTML Tags

Learning HTML involves becoming familiar with the available tags and understanding which attributes they support. The following are basic tags used when creating webpages.

Heading Tags

Heading tags organize webpage titles and subsections. HTML provides six heading levels, from <h1> to <h6>. 

<h1>Main Heading</h1>
<h2>Section Heading</h2>
<h3>Subsection Heading</h3>
<h4>Smaller Heading</h4>
<h5>Lower-Level Heading</h5>
<h6>Smallest Heading Level</h6>

The <h1> tag represents the most important heading, while <h6> represents the lowest heading level.

Paragraph Tag

The <p> tag defines a paragraph. It separates blocks of written content into readable sections. 

<p>
    HTML is used to structure webpage content.
</p>

Line breaks and blank lines in the HTML source code do not automatically create separate paragraphs in the browser. Use paragraph elements to organize text properly.

Other Frequently Used Tags

  • <a> – Creates a hyperlink.
  • <img> – Displays an image.
  • <ul> – Creates an unordered list.
  • <ol> – Creates an ordered list.
  • <li> – Defines a list item.
  • <div> – Groups content into a container.
  • <br> – Inserts a line break.
  • <strong> – Marks important text.
  • <em> – Emphasizes text.

HTML and CSS: Semantics and Presentation

HTML and CSS work together to create modern webpages. Although they are used together, they have different responsibilities.

HTML: Structure and Meaning

HTML focuses on the meaning and organization of webpage content. It identifies which parts are headings, paragraphs, lists, links, images, and other content.

CSS: Appearance and Presentation

CSS stands for Cascading Style Sheets. It controls how HTML content looks when displayed in a browser. It can define fonts, colors, spacing, borders, layouts, and other visual properties.

Semantic HTML

Semantic HTML means using elements according to the meaning of their content rather than choosing tags only for their visual appearance.

  • <strong>: Identifies text with strong importance.
  • <em>: Identifies emphasized text.
  • <b>: Draws attention to text without adding the same importance meaning as <strong>.
  • <i>: Represents text set apart from the normal text, such as a technical term or foreign phrase.

Semantic HTML helps browsers, developers, and assistive technologies understand the purpose of webpage content.

Difference Between HTML and CSS

  • HTML: Defines the webpage structure.
  • CSS: Controls the webpage appearance.
<h1>Welcome to My Website</h1>
<p>This is my first webpage.</p>
h1 {
    color: navy;
    text-align: center;
}

p {
    font-size: 16px;
}

The HTML creates the heading and paragraph, while CSS changes their appearance.

Basic HTML Rules

HTML follows rules that help browsers interpret webpage content correctly. Writing valid and properly organized markup helps prevent unexpected display problems.

Proper Nesting of Elements

HTML elements should be properly nested. An element must be completely contained within another element when it is placed inside it.

Correct example:

<b>
    <i>Welcome to HTML</i>
</b>

The italic element is completely contained inside the bold element.

Incorrect example:

<i>
    <b>Welcome to HTML</i>
</b>

The elements overlap instead of being properly nested. This can cause invalid markup.

Attribute Rules

  • Attributes are placed inside opening tags.
  • Attribute values should be enclosed in quotation marks.
  • Attributes may appear in different orders.
  • Use lowercase tag and attribute names consistently.

Void Elements

Some HTML elements do not wrap content and do not require a closing tag. These are called void elements.

  • <img> – Displays an image.
  • <br> – Inserts a line break.
  • <hr> – Creates a thematic break.
  • <meta> – Provides document metadata.
  • <input> – Creates an input control.

In HTML5, void elements do not need a closing slash. For example, <img src="photo.jpg" alt="Photo"> is valid HTML.

Block-Level and Inline Elements

HTML elements can be grouped according to how they are normally displayed and how they organize content.

  • Block-level elements: Usually begin on a new line and occupy the available width. Examples include <div>, <p>, and heading elements.
  • Inline elements: Usually appear within the flow of text and occupy only the space they need. Examples include <span>, <a>, and <strong>.

Inline elements are commonly placed inside block-level elements. However, valid nesting depends on the specific HTML element rules.

Overall HTML Document Structure

An HTML document is divided into two major sections: the head and the body. These sections organize the information about the webpage and the content that users see.

The Head Section

The <head> section contains information about the webpage. It is not normally displayed as the main page content.

It commonly contains:

  • Character encoding: Specifies how text characters should be interpreted, such as UTF-8.
  • Page title: Defines the title shown on the browser tab.
  • CSS references: Connects external stylesheets or contains internal styling.
  • Metadata: Provides additional information about the webpage.

The Body Section

The <body> section contains the actual webpage content displayed in the browser. This includes headings, paragraphs, images, links, lists, forms, and other visible elements.

Basic HTML Document Example

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>This is my first HTML webpage.</p>

</body>

</html>

Purpose of the Main Document Tags

  • <!DOCTYPE html>: Declares that the document uses HTML5.
  • <html>: The root element that contains the entire HTML document.
  • lang="en": Identifies English as the language of the webpage.
  • <meta charset="UTF-8">: Specifies the character encoding.
  • <title>: Sets the webpage title shown in the browser tab.
  • <head>: Contains document information and resource references.
  • <body>: Contains the content displayed on the webpage.

WYSIWYG and Web Design

WYSIWYG stands for "What You See Is What You Get." It refers to applications that allow users to edit a document while seeing a visual representation of how the final output will appear.

Word processors are common examples. Users can select fonts, adjust text sizes, add images, and format documents while viewing the results.

Why WYSIWYG Is Different for Websites

Unlike printed documents, webpages can be viewed on different devices and screen sizes. A website may be displayed on a desktop computer, laptop, tablet, smartphone, or television.

Different browsers may also interpret or display webpage content differently. A page that looks correct in one browser may have small differences in another.

Important Considerations

  • Screen resolution: Websites should work on different screen sizes and resolutions.
  • Device compatibility: Layouts should support desktops, laptops, tablets, and mobile devices.
  • Browser compatibility: Websites should be tested in the browsers used by their intended visitors.
  • Responsive design: Layouts should adjust to different display sizes and user environments.
  • Testing: Developers should check how webpages behave across different platforms.

The lecture emphasizes that what a developer sees on their own screen is not necessarily what every visitor will see. This is why webpages must be tested on different devices and browsers.

HTML Validation

HTML validation is the process of checking whether webpage code follows the rules and requirements of the HTML specification.

Web browsers are designed to display webpages even when some errors are present. They may attempt to correct or interpret invalid markup automatically. However, different browsers may handle the same errors in different ways.

Why HTML Validation Is Important

  • Helps identify missing or incorrectly written tags.
  • Detects invalid HTML syntax and nesting.
  • Improves consistency across browsers.
  • Helps developers find problems before publishing.
  • Encourages clean and well-organized webpage code.

HTML Validator

An HTML validator is a tool that checks HTML code against established standards. Developers can use the official W3C validator to identify errors and warnings in their webpages.

Open the W3C HTML Validator

After checking the code, developers should correct the reported issues and validate the webpage again.

HTML5

HTML5 is the major version of HTML discussed in the lecture. It includes the markup language and additional browser-related capabilities that support modern web applications.

HTML5 Features

  • Geolocation: Allows a browser to request location information, such as latitude and longitude, when permitted by the user.
  • Canvas: Provides a drawing area that can be controlled through programming.
  • Web Storage: Allows information to be stored locally in the browser for access by client-side programs.

In everyday use, the term HTML5 may refer not only to HTML itself but also to modern web technologies commonly used with it, including CSS and JavaScript.

Organizations Involved in HTML Standards

  • World Wide Web Consortium (W3C): An organization responsible for developing standards and specifications for the Web.
  • WHATWG: The Web Hypertext Application Technology Working Group, which includes browser developers and maintains the HTML Living Standard.

The lecture explains that these groups have different approaches to HTML development. WHATWG favors a continuously updated Living Standard rather than treating HTML as a language with fixed numbered versions.

XML and XHTML

Extensible Markup Language (XML)

XML stands for Extensible Markup Language. It is a markup framework used to define structured data and create other markup languages. It provides rules for organizing information through tags, elements, attributes, and values.

XML is not limited to webpages. It can be used in different fields that need structured information.

Examples of XML-Based Languages

  • CML (Chemical Markup Language): Used to represent chemical information such as atoms, molecules, and bonds.
  • MathML (Mathematical Markup Language): Used to describe mathematical expressions and equations.
  • SVG (Scalable Vector Graphics): Used to create scalable drawings and graphics that modern browsers can display.

Scalable Vector Graphics (SVG)

SVG is an XML-based format for describing graphics using objects such as circles, rectangles, lines, and text. Unlike ordinary bitmap images, vector graphics can be scaled without losing their mathematical shape definitions. 

<svg width="300" height="200"
     xmlns="http://www.w3.org/2000/svg">

    <circle cx="100" cy="100" r="50"
            fill="red" />

    <rect x="150" y="50" width="100"
          height="100" fill="none"
          stroke="blue" stroke-width="5" />

</svg>

This example creates a red circle and a blue outlined rectangle using SVG elements.

XML Syntax Rules

  • Tag and attribute names must be written in lowercase.
  • Attribute values must be enclosed in quotation marks.
  • Elements must be properly nested.
  • Elements must have matching closing tags unless they are written as empty elements.

XHTML

XHTML is a variant of HTML based on XML. It follows stricter syntax rules, including properly written tags, lowercase names, quoted attribute values, and properly closed elements.

Standard HTML5 is more flexible in its syntax. For example, HTML5 does not require a closing slash for void elements such as <img>.

How to Create a Webpage

Creating an HTML webpage begins with writing the markup in a text editor. A text editor is designed for working with plain text and source code, unlike a word processor that focuses on formatted documents.

Text Editors

The lecture introduces several text editors that can be used for writing HTML files:

  • Notepad++: A Windows text editor with syntax highlighting and code-editing features.
  • Notepad: A basic Windows text editor suitable for simple HTML files.
  • TextWrangler and BBEdit: Text editors mentioned for Macintosh computers.
  • Sublime Text: A code editor available for multiple operating systems.
  • Atom: Another code editor mentioned in the lecture.

Creating an HTML File

Developers can begin with an existing HTML template instead of creating the document structure from nothing. They can then add their own headings, paragraphs, links, images, and other content.

Testing a Webpage Locally

A webpage does not need to be uploaded to a web server just to be tested. Developers can open an HTML file directly from their computer using a web browser.

  • Save the source code with an .html extension.
  • Locate the saved file on the computer.
  • Open it using a web browser.
  • Check whether the content appears correctly.
  • Return to the source code and correct any problems.
  • Use an HTML validator to check the markup.

Putting a Webpage on the Internet

A webpage saved on a personal computer can be viewed locally, but other people cannot access it through the Internet unless it is made available through a web server or hosting service.

Web Hosting

Web hosting is the process of storing website files on a server so that visitors can access them through a web address.

Before publishing, developers should thoroughly test and validate their HTML files. This helps prevent errors from appearing on the public website.

Website File Organization

The lecture recommends using simple and consistent filenames for files that will be placed on the Web.

  • Use lowercase letters.
  • Use numbers when needed.
  • Use hyphens to separate words.
  • Avoid unnecessary symbols and spaces.
  • Use the correct file extension, such as .html or .css.

Example of good filenames:

index.html
about-us.html
contact-page.html
style.css
school-logo.png

Clear filenames make website files easier to organize, manage, and link together.

Practical HTML Examples

Creating a Simple Webpage

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>Student Profile</title>
</head>

<body>

    <h1>Student Profile</h1>

    <h2>Personal Information</h2>

    <p>Name: Juan Dela Cruz</p>
    <p>Course: Bachelor of Science in Information Technology</p>

    <a href="https://www.example.com">
        Visit Website
    </a>

</body>

</html>

Adding an Image

<img src="images/student.jpg"
     alt="Student working on a computer">

The src attribute specifies the image location, while alt provides a text description if the image cannot be displayed or is accessed through assistive technology.

Creating a List

<h2>My Subjects</h2>

<ul>
    <li>Web Development</li>
    <li>Database Management</li>
    <li>Computer Networking</li>
</ul>

Creating a Hyperlink

<a href="https://www.google.com">
    Open Google
</a>

Key Takeaways

  • HTML stands for HyperText Markup Language and provides structure to webpages.
  • The Web uses a client-server architecture to request and deliver webpage resources.
  • HTTP is used by clients and servers to communicate.
  • HTML tags identify and organize different types of webpage content.
  • An HTML element consists of its tags and the content contained between them.
  • Attributes provide additional information about HTML elements.
  • HTML focuses on content structure and meaning, while CSS controls presentation.
  • Proper nesting, syntax, and document structure help create valid HTML.
  • HTML5 includes browser capabilities such as Geolocation, Canvas, and Web Storage.
  • XML provides rules for creating structured markup languages, while XHTML applies XML-style rules to HTML.
  • Webpages should be tested and validated before being published online.
  • A website must be placed on a web server or hosting service to be accessible to other people through the Internet.
