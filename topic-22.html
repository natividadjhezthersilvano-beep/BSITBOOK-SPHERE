Overview of Introduction to HTML

HyperText Markup Language, commonly known as HTML, is the standard markup language used to create and organize content on webpages. It provides the structure and meaning of information displayed through a web browser.

HTML allows developers to organize text, headings, paragraphs, links, images, and other webpage elements using tags and attributes. These elements help browsers understand how different parts of a webpage are organized.

Modern websites use HTML together with Cascading Style Sheets (CSS) and JavaScript. HTML provides the structure, CSS controls the presentation, and JavaScript adds interactive behavior.

Learning Objectives

  • Understand how the World Wide Web works.
  • Explain the purpose of HTML in web development.
  • Identify HTML tags, elements, and attributes.
  • Understand the relationship between HTML and CSS.
  • Recognize the basic rules of writing valid HTML.
  • Understand the structure of an HTML document.
  • Learn how to create, test, validate, and publish webpages.

How the Web Works

The World Wide Web allows people to access and share information through websites. When someone opens a webpage, the browser communicates with a web server to request the resources needed to display that page.

Understanding the Client-Server Architecture

The web uses a client-server architecture. This architecture involves two main types of computers: clients and servers.

  • Client: A device or application that requests information from a server. A computer running a web browser is an example of a client.
  • Server: A computer or system that waits for requests and provides the requested resources.

For example, when a user enters a website address into Google Chrome, the browser sends a request to the server hosting that website. The server processes the request and sends the required webpage resources back to the browser.

How a Webpage Is Requested

  • The user enters a URL (Uniform Resource Locator) into a web browser.
  • The browser identifies the web server associated with the requested website.
  • The browser communicates with the server using HTTP (HyperText Transfer Protocol).
  • The web server receives and processes the request.
  • The server sends the requested resource back to the browser.
  • The browser reads the returned resources and displays the webpage.

HTTP and Web Resources

HTTP is a general-purpose communication protocol used to transfer digital information over the Internet. It allows browsers and web servers to exchange different types of resources.

Common resources transferred through HTTP include:

  • HTML files: Contain webpage content and semantic information.
  • CSS files: Contain formatting and styling instructions for webpages.
  • Image files: Include formats such as JPEG, PNG, and GIF.

Functions of a Web Browser

A web browser performs several tasks to make websites accessible to users.

  • Communicates with web servers using HTTP.
  • Reads and interprets HTML documents.
  • Applies CSS formatting to webpage content.
  • Displays images and other website resources.
  • Uses a JavaScript engine to execute client-side programs.

Introduction to HTML

HTML stands for HyperText Markup Language. It is used to organize and describe the content of webpages. HTML provides instructions that help a browser understand the different parts of a document.

HTML is not a traditional programming language. It is a markup language because it uses tags and elements to identify and organize webpage content.

Purpose of HTML

  • Creates the structure of webpages.
  • Organizes information into headings and paragraphs.
  • Connects webpages through hyperlinks.
  • Displays images and other media.
  • Provides meaningful structure for browsers and assistive technologies.
  • Works with CSS and JavaScript to build complete websites.

Example of HTML

The following example shows how HTML tags can organize simple webpage content. 

<h1>Welcome to My Website</h1>

<p>
    This is my first HTML webpage.
</p>

<a href="https://www.example.com">
    Visit Website
</a>

The heading displays the main title, the paragraph contains descriptive text, and the anchor element creates a clickable link.

Understanding Hypertext and Markup

Hypertext

Hypertext is a system of connecting information through links. It allows users to move from one document or resource to another without following a fixed, linear order.

In a traditional printed book, pages are normally read in sequence. With hypertext, a user can select a link and immediately open another webpage, document, or resource.

The World Wide Web combines hypertext with the Internet, allowing information from different websites to be connected and accessed.

Hypermedia

Hypermedia expands the concept of hypertext by allowing links to connect not only written information but also other forms of media.

Examples include links to images, audio recordings, videos, and other multimedia resources.

Markup

Markup refers to instructions added to a document to describe how its content should be organized or interpreted. The concept originally came from publishing, where editors added notes to articles to guide typesetters about how the material should be prepared for printing.

In HTML, markup is written using tags that identify the meaning and structure of webpage content.

HTML as a Language

HTML is considered a language because it follows specific syntax rules and uses a defined set of elements and attributes. Developers must follow these rules so that browsers can correctly interpret the document.

HTML Tags and Elements

HTML uses tags to mark and organize content. Tags provide instructions that tell the browser what type of information is contained in a particular part of the document.

What Are HTML Tags?

Tags are written using angle brackets. Most elements have an opening tag and a closing tag. The closing tag contains a forward slash before the tag name. 

<b>Stanford</b>

In this example, <b> is the opening tag and </b> is the closing tag. The word Stanford is the content inside the tags.

What Are HTML Elements?

An HTML element consists of the opening tag, the content, and the closing tag. It acts as a container for a specific piece of webpage information.

Examples of HTML Tags

  • <h1> to <h6>: Define headings, from the most important heading to lower-level headings.
  • <p>: Defines a paragraph.
  • <b>: Displays text in bold.
  • <i>: Displays text in italic.
  • <a>: Creates a hyperlink.
  • <img>: Embeds an image.
  • <br>: Creates a line break.

Text-Level and Block-Level Elements

HTML elements can be grouped according to how they organize content.

  • Text-level elements: Used within text to identify or emphasize individual words and short phrases. Examples include <strong>, <em>, and <b>.
  • Block-level elements: Used to organize larger sections of content. Examples include headings, paragraphs, and other structural elements.

Example of Nested Elements

HTML elements can be placed inside other elements when the structure allows it. This is called nesting. 

<p>
    I am learning <strong>HTML</strong>.
</p>

The strong element is correctly placed inside the paragraph element.

HTML Attributes

Attributes provide additional information about HTML elements. They are written inside the opening tag and usually contain a name and a value.

Purpose of Attributes

  • Provide additional details about an element.
  • Specify the destination of a hyperlink.
  • Identify the location of an image file.
  • Provide alternative text for images.
  • Help control how certain HTML elements behave.

Example of an Anchor Attribute

The anchor element creates a hyperlink. The href attribute specifies the destination address of the link. 

<a href="https://www.example.com">
    Visit Example Website
</a>

In this example, href is the attribute name, while the website address is its value.

Common HTML Attributes

  • href: Specifies the destination of a hyperlink.
  • src: Specifies the location of an external resource, such as an image.
  • alt: Provides alternative text describing an image.
  • id: Identifies a unique element within a webpage.
  • class: Groups elements for styling or scripting.
  • title: Provides additional descriptive information.

Image Attribute Example

<img
    src="computer.jpg"
    alt="A desktop computer"
>

The src attribute identifies the image file, while alt provides a text description of the image.

Attribute order generally does not change the meaning of an element. For example, src and alt can appear in either order.

Learning HTML

Learning HTML involves understanding the available elements, knowing when to use them, and learning which attributes provide additional functionality.

Developers do not need to memorize every HTML element. They can use reliable documentation and references to find the appropriate elements and attributes when developing a webpage.

Important HTML Elements to Learn

  • Heading elements: <h1> through <h6> organize titles and subsections.
  • Paragraph element: <p> organizes blocks of written content.
  • Anchor element: <a> connects webpages and resources.
  • Image element: <img> displays pictures and graphics.
  • List elements: <ul>, <ol>, and <li> organize information into lists.

Heading Hierarchy

HTML provides six heading levels. The h1 element represents the main heading, while h2 to h6 represent increasingly lower levels of headings. 

<h1>Introduction to HTML</h1>

<h2>HTML Elements</h2>

<h3>HTML Tags</h3>

<h4>Opening and Closing Tags</h4>

Paragraphs

The paragraph element is used to organize written information. Blank lines or line breaks in the HTML source code do not automatically create separate paragraphs in the browser. 

<p>HTML creates the structure of a webpage.</p>

<p>CSS controls the presentation of the webpage.</p>

Each paragraph should be placed inside its own paragraph element.

HTML and CSS: Semantics and Presentation

HTML and CSS work together to create modern webpages. Although they are closely related, they have different responsibilities.

HTML: Structure and Meaning

HTML focuses on the meaning and organization of webpage content. It identifies which parts of a document are headings, paragraphs, links, images, lists, and other types of information.

CSS: Presentation and Appearance

CSS stands for Cascading Style Sheets. It controls how HTML content appears on the screen. CSS can change colors, fonts, spacing, borders, backgrounds, and page layouts.

Semantic HTML

Semantic HTML means using elements according to their meaning and purpose instead of selecting elements only because of how they look.

For example, a heading should be marked using a heading element rather than using an unrelated element simply to make the text appear larger.

Emphasis and Strong Importance

  • <em>: Identifies emphasized text.
  • <strong>: Identifies text with strong importance.
  • <i>: Represents text set apart from the surrounding text, such as a technical term or foreign phrase.
  • <b>: Draws attention to text without necessarily indicating additional importance.

Browsers commonly display em and i in italic styling, and strong and b in bold styling by default. However, their meanings are different.

Why Semantic HTML Matters

  • Makes webpage content easier to understand.
  • Improves document organization.
  • Helps assistive technologies interpret content.
  • Makes webpages easier to maintain.
  • Separates content meaning from visual styling.

Basic HTML Rules

HTML follows structural and syntax rules that developers should observe when writing webpages. Following these rules helps browsers interpret documents consistently.

Properly Nest HTML Elements

HTML elements must be properly nested. This means an element should be completely contained inside another element when nesting is allowed.

Correct nesting:

<b>
    <i>Hello World</i>
</b>

The italic element is completely contained inside the bold element.

Incorrect nesting:

<i>
    <b>Hello World
</i>
    </b>

The elements overlap instead of being properly contained within each other.

Use Proper Opening and Closing Tags

Most HTML elements require both opening and closing tags. The closing tag uses a forward slash before the element name. 

<p>This is a paragraph.</p>

Use Correct Attribute Syntax

Attribute values should be enclosed in quotation marks. HTML attribute names are not case-sensitive in standard HTML, but lowercase names and quoted values are recommended for consistent code. 

<img src="photo.jpg" alt="Sample photo">

The order of attributes does not normally affect how the element works.

Void Elements

Some HTML elements do not contain content and do not use separate closing tags. These are called void elements.

Examples include:

  • <img> for embedding images.
  • <br> for creating line breaks.
  • <hr> for thematic breaks.
  • <meta> for document metadata.
  • <input> for form input controls.

In modern HTML, these elements do not require a trailing slash. The slash may appear in some coding styles, but it is not required.

Follow Element Content Rules

Not every HTML element can contain every other element. For example, a paragraph should not contain another paragraph or a heading.

Correct example:

<p>
    I am studying <strong>web development</strong>.
</p>

Incorrect example:

<p>
    This is a paragraph.
    <h2>Another Heading</h2>
</p>

The heading should be placed outside the paragraph element.

Overall HTML File Structure

An HTML document is divided into two main sections: the head and the body. Each section has a different purpose in describing and displaying a webpage.

Document Structure

The Head Section

The head section contains information about the webpage. Much of this information is not directly displayed as page content.

It commonly contains:

  • Character encoding: Specifies how characters are represented, commonly using UTF-8.
  • Page title: Specifies the title displayed on the browser tab.
  • CSS references: Connects the webpage to external stylesheets.
  • Metadata: Provides information about the document.

The Body Section

The body contains the actual content displayed to visitors. This includes headings, paragraphs, images, links, lists, tables, forms, and other webpage elements.

Basic HTML Document Example

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>My First Webpage</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is my first HTML webpage.
    </p>

</body>

</html>

Important Parts of the Document

  • <!DOCTYPE html>: Declares the document as an HTML document and helps browsers use standards mode.
  • <html lang="en">: Identifies the root element and specifies that the document language is English.
  • <meta charset="UTF-8">: Specifies the character encoding.
  • <title>: Defines the title shown on the browser tab.
  • <body>: Contains the webpage's visible content.

WYSIWYG: What You See Is Not Necessarily What You Get

WYSIWYG stands for What You See Is What You Get. It refers to editing applications that display a document in a form that closely resembles its final appearance.

Word processors such as Microsoft Word allow users to see how a document will look when printed. Users can select page sizes, margins, fonts, and layouts while editing.

Why WYSIWYG Is Different on the Web

Webpages are displayed on many different devices and browsers. A developer does not control the exact screen size, resolution, browser, or operating environment that every visitor uses.

A webpage may be opened using a desktop computer, laptop, tablet, smartphone, or television. These devices have different screen dimensions and display capabilities.

Factors That Affect Webpage Appearance

  • Screen resolution and display size.
  • Browser differences.
  • Device type and orientation.
  • Available fonts and display settings.
  • Responsive layout and styling.

Cross-Browser and Device Testing

Developers should test webpages on different browsers and devices to check whether content is displayed correctly.

They should also consider the screen sizes and device types they intend to support. A design that works well on a desktop may not work properly on a small touchscreen.

This is why testing is an important part of web development. What appears correctly on the developer's screen may not look exactly the same for every visitor.

HTML Validation

HTML validation is the process of checking whether an HTML document follows the rules and requirements of the HTML standard.

Browsers are designed to display webpages even when they contain certain HTML errors. Instead of stopping completely, browsers often attempt to interpret and display the document as best they can.

Why Validation Is Important

  • Identifies errors in HTML syntax.
  • Helps detect missing or incorrectly placed tags.
  • Finds invalid element nesting.
  • Improves consistency between browsers.
  • Makes webpages easier to maintain.
  • Helps developers follow web standards.

What Happens When HTML Is Invalid?

Different browsers may handle incorrect HTML in different ways. One browser may automatically correct a mistake, while another may interpret the same code differently.

These differences can result in inconsistent layouts, unexpected content, and difficult debugging problems.

HTML Validator

An HTML validator is a tool that checks a webpage's markup and reports errors or warnings. Developers can use it to identify problems before publishing a website.

The official W3C validator is available here:

W3C Markup Validation Service

Validation Process

  • Write the HTML document.
  • Open the W3C validation service.
  • Submit the HTML file or webpage address.
  • Review the errors and warnings.
  • Correct the problems in the source code.
  • Validate the webpage again.

HTML5

HTML5 introduced features that expanded the capabilities of webpages and web applications. It includes modern semantic elements and browser features that support interactive and multimedia experiences.

HTML5 Features

Geolocation

Geolocation allows a website, with the user's permission, to request location information from a supported browser or device.

Location information may include latitude and longitude, along with other supported location details.

Canvas

The canvas element provides an area where JavaScript can draw graphics. Developers can use it to create drawings, animations, charts, and other visual content. 

<canvas id="myCanvas"
        width="300"
        height="150">
</canvas>

Web Storage

Web Storage allows websites to store data locally in a user's browser. This data can be accessed by client-side programs and can help websites remember certain information.

Common Web Storage mechanisms include localStorage and sessionStorage.

HTML5 and Modern Web Technologies

In everyday discussions, the term HTML5 may refer not only to HTML itself but also to technologies commonly used together to build modern websites, such as CSS and JavaScript.

W3C and WHATWG

The development of HTML standards has involved different organizations and approaches. The lecture discusses two organizations: the World Wide Web Consortium (W3C) and the Web Hypertext Application Technology Working Group (WHATWG).

  • W3C: An organization that develops standards and specifications for the World Wide Web.
  • WHATWG: A group closely associated with browser developers that maintains the HTML Living Standard.

The lecture describes their different approaches to HTML development. WHATWG favors a continuously updated Living Standard instead of treating HTML as a specification that stops at a numbered version.

XML and Other Markup Languages

XML stands for Extensible Markup Language. It provides a set of rules for creating markup languages that organize and describe information using tags and attributes.

Unlike HTML, which uses a predefined set of elements for webpage content, XML allows developers to define their own tags according to the type of information they need to describe.

Purpose of XML

  • Organizes structured information.
  • Allows developers to define custom tags.
  • Supports data exchange between systems.
  • Provides a consistent format for storing information.
  • Serves as a foundation for other markup languages.

XML-Based Markup Languages

Several markup languages have been developed using XML rules.

  • CML (Chemical Markup Language): Used to describe chemical information, including atoms, molecules, and bonds.
  • MathML (Mathematical Markup Language): Used to represent mathematical equations and expressions.
  • SVG (Scalable Vector Graphics): Used to describe two-dimensional graphics using shapes, lines, and text.

SVG Graphics

SVG allows developers to create scalable graphics using code. Since SVG describes objects such as circles, rectangles, and lines, the graphics can be resized without losing their sharpness.

Basic XML Syntax Rules

  • Element names must follow XML naming rules.
  • Every opened element must have a matching closing tag.
  • Elements must be properly nested.
  • Attribute values must be enclosed in quotation marks.
  • XML documents must have a single root element.
  • XML names are case-sensitive.

Example of XML

<student>
    <name>Juan Dela Cruz</name>
    <course>BSIT</course>
    <year>Third Year</year>
</student>

In this example, the student element contains information about a student. The name, course, and year elements describe individual pieces of data.

HTML and XHTML

XHTML is a variant of HTML designed to follow stricter XML syntax rules. It requires well-formed markup, properly nested elements, and correctly written attributes.

Modern HTML does not require every XML rule. For example, standard HTML allows certain closing tags to be omitted in situations defined by the HTML specification. However, writing clear and properly structured HTML remains a good development practice.

How to Create a Webpage

Creating an HTML webpage begins with writing code in a text editor. The developer saves the document with an HTML file extension and opens it in a web browser to see how it appears.

Choose a Text Editor

A text editor is an application used to write and edit plain text files, including HTML and CSS source code.

Text editors are different from word processors because they work directly with source code instead of automatically applying document formatting.

Examples of Text Editors

  • Notepad: A basic text editor included with Windows.
  • Notepad++: A source code editor with syntax highlighting and additional development features.
  • Sublime Text: A code editor available for different operating systems.
  • BBEdit: A text editor for macOS.
  • Visual Studio Code: A popular code editor with extensions and development tools.

Start with an HTML Template

Instead of creating every webpage from nothing, developers can begin with a basic HTML template. They can then add the content and elements needed for their project.

Write and Save the HTML File

  • Open a text editor.
  • Create a new document.
  • Write the HTML structure and content.
  • Save the file using the .html extension.
  • Keep related images and other resources organized.

Test the Webpage in a Browser

HTML files can be opened directly from a computer without uploading them to a web server. A developer can open the saved file using a browser or drag the file into a browser window.

After opening the webpage, check whether the headings, paragraphs, links, images, and other elements appear correctly.

Debugging Webpage Problems

If the webpage does not appear correctly, return to the HTML source file and inspect the code. Check for missing tags, incorrect file paths, spelling errors, and invalid nesting.

Putting a Webpage on the Web

A webpage stored on a personal computer can be viewed locally, but other people cannot normally access it through a public website address. To make a webpage available online, it must be uploaded to a web server or hosting service.

What Is Web Hosting?

Web hosting is a service that stores website files on a server and makes them accessible through the Internet. When visitors enter the website address, the server delivers the requested webpage resources to their browsers.

Before Publishing a Website

  • Check that the HTML code is properly structured.
  • Validate the HTML documents.
  • Test the website using different browsers.
  • Check the layout on different screen sizes.
  • Make sure images and other resources load correctly.
  • Check that navigation links work properly.

Uploading Website Files

After testing, developers can upload their HTML files, stylesheets, images, and other website resources to a web hosting server. The hosting service provides an address through which visitors can access the website.

Organizing Website File Names

Clear and consistent file names help developers manage website resources and reduce problems when uploading files.

  • Use lowercase letters for file names.
  • Use numbers when necessary.
  • Use hyphens to separate words.
  • Avoid unnecessary spaces and special characters.
  • Use the correct file extension, such as .html or .css.

Example of organized file names:

index.html
about-us.html
contact-page.html
style.css
computer-image.jpg

Practical HTML Example

The following example combines the concepts discussed in this lesson. It demonstrates how to create a simple webpage using HTML headings, paragraphs, links, images, and semantic elements.

Sample HTML Webpage

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First HTML Website</title>
</head>

<body>

    <header>
        <h1>My First HTML Website</h1>

        <p>
            Welcome to my personal webpage.
        </p>
    </header>

    <main>

        <section>
            <h2>About HTML</h2>

            <p>
                HTML is used to create the structure
                and content of webpages.
            </p>
        </section>

        <section>
            <h2>Learning Resources</h2>

            <p>
                Visit this website to learn more:
            </p>

            <a href="https://www.w3schools.com/html/">
                Learn HTML
            </a>
        </section>

        <section>
            <h2>Sample Image</h2>

            <img src="computer.jpg"
                 alt="A desktop computer">
        </section>

    </main>

    <footer>
        <p>My First HTML Website</p>
    </footer>

</body>

</html>

Explanation of the Example

  • The DOCTYPE declaration identifies the document as HTML.
  • The html element contains the entire document.
  • The head contains metadata and the webpage title.
  • The body contains the visible content.
  • The header introduces the webpage.
  • The main element contains the primary information.
  • The section elements organize related content.
  • The anchor element creates a link to an external learning resource.
  • The image element displays a picture and provides alternative text.
  • The footer contains information at the bottom of the webpage.

Key Takeaways

  • HTML stands for HyperText Markup Language and provides the structure of webpages.
  • The web uses a client-server architecture in which browsers request resources from web servers.
  • HTTP is used to transfer webpage resources between clients and servers.
  • HTML tags and elements organize webpage content.
  • Attributes provide additional information about HTML elements.
  • Semantic HTML describes the meaning and purpose of webpage content.
  • CSS controls the visual presentation of HTML content.
  • HTML elements must be properly nested and follow their content rules.
  • An HTML document contains a head section and a body section.
  • Websites should be tested on different devices and browsers.
  • HTML validators help identify markup errors and improve code quality.
  • HTML5 includes features such as Canvas, Geolocation, and Web Storage.
  • XML provides rules for creating structured markup languages.
  • Webpages can be created locally and published online through a web server or hosting service.
