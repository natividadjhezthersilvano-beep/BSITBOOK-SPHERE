Overview

Number systems and data representation are important concepts in computer science. They explain how computers store, process, and communicate different types of information using digital values.

Unlike humans, who commonly use the decimal number system, computers primarily use the binary number system, which consists of only two digits: 0 and 1.

Text, images, audio, videos, and other types of information must be converted into digital representations before computers can process and store them.

Learning Objectives

After completing this lesson, students should be able to:

  • Explain the concept of data representation.
  • Identify the different number systems used in computing.
  • Convert numbers between binary, decimal, octal, and hexadecimal.
  • Explain how characters and numeric values are represented.
  • Understand signed and unsigned integer representation.
  • Perform basic binary arithmetic operations.
  • Describe floating-point and BCD representation.
  • Identify different data types and their uses.

Data Representation

Data representation refers to the method used by computers to express information in a form that can be understood and processed by electronic systems.

Computers represent information using binary digits, commonly called bits. A bit can have only one of two possible values: 0 or 1.

Analog and Digital Representation

Information can be represented in analog or digital form. Analog representation uses continuous values, while digital representation uses separate and discrete values.

Analog Representation

Analog representation uses continuous signals that can change smoothly over time. It can represent physical quantities such as temperature, sound, and light.

Examples include:

  • Traditional analog clocks
  • Vinyl record audio signals
  • Mercury thermometers
  • Analog radio signals

Digital Representation

Digital representation stores information using discrete values. Computers commonly use binary digits to represent digital information.

Examples include:

  • Digital photographs
  • Computer documents
  • Digital music files
  • Videos stored on computers
  • Electronic databases

Bits and Bytes

A bit is the smallest unit of digital information. A byte consists of eight bits and is commonly used to measure computer memory and storage.

Unit Equivalent
Bit One binary digit (0 or 1)
Byte 8 bits
Kilobyte (KB) 1,000 bytes
Megabyte (MB) 1,000 KB
Gigabyte (GB) 1,000 MB
Terabyte (TB) 1,000 GB

Storage manufacturers commonly use decimal units (1 KB = 1,000 bytes). Operating systems and technical contexts may also use binary units such as KiB, where 1 KiB = 1,024 bytes.

Why Do Computers Use Binary?

Computers use binary because their electronic circuits can distinguish between two states, such as ON and OFF. These states can be represented by 1 and 0.

  • 0 represents a low or OFF state.
  • 1 represents a high or ON state.

Binary Place Values

Each binary position represents a power of two. The rightmost position starts with 2⁰, followed by 2¹, 2², 2³, and so on.

Position Power Value

Number Systems

A number system is a method of representing numerical values using a specific set of digits and a base. The base determines how many different digits are available in the system.

Binary Number System

The binary number system has a base of 2 and uses only two digits: 0 and 1. It is the primary number system used by digital computers.

Example:

1010₂ = 10₁₀

Decimal Number System

The decimal number system has a base of 10. It uses ten digits, from 0 to 9, and is the number system commonly used in everyday life.

Example:

245₁₀

Octal Number System

The octal number system has a base of 8. It uses the digits 0 through 7. Each octal digit can represent a group of three binary bits.

Example:

157₈

Hexadecimal Number System

The hexadecimal number system has a base of 16. It uses the digits 0 through 9 and the letters A through F.

The letters A, B, C, D, E, and F represent decimal values 10, 11, 12, 13, 14, and 15.

Example:

2F₁₆

Comparison of Number Systems

Number System Base Digits Used
Binary 2 0 and 1
Decimal 10 0 to 9
Octal 8 0 to 7
Hexadecimal 16 0 to 9 and A to F

Number System Conversions

Number system conversion is the process of changing a numerical value from one number system to another without changing its actual value.

Binary to Decimal

To convert binary to decimal, multiply each binary digit by its corresponding power of two and add the results.

Example: Convert 1011₂ to decimal.

1011₂

= (1 × 2³) + (0 × 2²) + (1 × 2¹) + (1 × 2⁰)

= 8 + 0 + 2 + 1

= 11₁₀

Decimal to Binary

To convert decimal to binary, repeatedly divide the number by 2. Record each remainder and read the remainders from bottom to top.

Example: Convert 25₁₀ to binary.

Division Quotient Remainder
25 ÷ 2121
12 ÷ 260
6 ÷ 230
3 ÷ 211
1 ÷ 201
 
Read the remainders from bottom to top.

25₁₀ = 11001₂

Decimal to Octal

Example: Convert 156₁₀ to octal.

Division Quotient Remainder
156 ÷ 8194
19 ÷ 823
2 ÷ 802
 
Read from bottom to top.

156₁₀ = 234₈

Decimal to Hexadecimal

Example: Convert 254₁₀ to hexadecimal.

Division Quotient Remainder
254 ÷ 161514 (E)
15 ÷ 16015 (F)
 
Read from bottom to top.

254₁₀ = FE₁₆

Hexadecimal to Decimal

Example: Convert 2F₁₆ to decimal.

2F₁₆

= (2 × 16¹) + (15 × 16⁰)

= 32 + 15

= 47₁₀

Binary to Octal

Group the binary digits into sets of three, starting from the right. Convert each group into its corresponding octal digit.

Example: Convert 110101₂ to octal.

110 101

110 = 6
101 = 5

Answer: 65₈

Binary to Hexadecimal

Group the binary digits into sets of four, starting from the right. Convert each group into its corresponding hexadecimal digit.

Example: Convert 11101111₂ to hexadecimal.

1110 1111

1110 = E
1111 = F

Answer: EF₁₆

Character Representation

Computers must represent letters, numbers, punctuation marks, and symbols using numerical codes. Character encoding provides a standard method for converting characters into values that computers can store and process.

ASCII

ASCII stands for American Standard Code for Information Interchange. The original ASCII standard uses 7 bits and can represent 128 different characters.

These include uppercase and lowercase letters, numbers, punctuation marks, and control characters.

ASCII Examples

EBCDIC

EBCDIC stands for Extended Binary Coded Decimal Interchange Code. It is an 8-bit character encoding system associated with IBM mainframe computers.

Unicode

Unicode is a universal character standard designed to represent characters from many languages and writing systems. It also includes symbols and emoji.

Unicode Encoding Forms

  • UTF-8: Uses one to four bytes to encode a Unicode character.
  • UTF-16: Uses one or two 16-bit code units.
  • UTF-32: Uses one 32-bit code unit per Unicode code point.

Comparison of Character Encoding

EBCDIC 8-bit encoding associated with IBM mainframes.
Unicode Universal standard for representing characters from many writing systems.

Numeric Data Representation

Numeric data representation explains how computers store and process numerical values. These values can be whole numbers or numbers containing fractional parts.

Numeric data is commonly divided into:

  • Integer numbers
  • Floating-point numbers

Integer Numbers

Integers are whole numbers without fractional or decimal parts. Examples include 5, 20, 100, -10, and -25.

Floating-Point Numbers

Floating-point numbers represent values that may contain fractional or decimal parts. Examples include 3.14, 25.75, and -10.5.

Numeric Representation Comparison

Type Example Purpose
Integer 25 Stores whole numbers.
Floating-point 25.75 Stores numbers with fractional values.

Integer Representation

Integer representation is the method computers use to store whole numbers in binary form. Integers can be represented as signed or unsigned.

Unsigned Integers

Unsigned integers represent zero and positive values only. All available bits are used to represent the numerical value.

For example, an 8-bit unsigned integer can represent values from 0 to 255. 

Minimum: 00000000 = 0
Maximum: 11111111 = 255

Signed Integers

Signed integers can represent positive and negative numbers. One common method used to represent signed integers is two's complement.

Two's Complement

Two's complement is a binary representation commonly used to store signed integers. It allows computers to perform addition and subtraction using the same basic arithmetic circuits.

To obtain the two's complement of a binary number:

  1. Invert all bits, changing 0 to 1 and 1 to 0.
  2. Add 1 to the inverted binary number.

Example: Represent -5 using 8-bit two's complement.

Positive 5:

00000101

Invert all bits:

11111010

Add 1:

11111010
       +1
--------
11111011

Therefore:

-5 = 11111011

Most Significant Bit and Least Significant Bit

The most significant bit (MSB) is the leftmost bit in a binary number. It has the highest positional value.

The least significant bit (LSB) is the rightmost bit. It has the lowest positional value. 

Example:

10110110

MSB = 1
LSB = 0

Signed and Unsigned Comparison

Representation 8-Bit Range
Unsigned Integer 0 to 255
Signed Two's Complement -128 to 127

Binary division follows the same general process as long division in the decimal system.

Binary Fractions

Binary fractions represent values smaller than one using digits after the binary point. Each position after the point represents a negative power of two.

The first position after the binary point represents 2⁻¹, followed by 2⁻², 2⁻³, and so on.

Position Power Decimal Value
1st2⁻¹0.5
2nd2⁻²0.25
3rd2⁻³0.125
4th2⁻⁴0.0625

Binary Fraction to Decimal

Example: Convert 0.101₂ to decimal.

0.101₂

= (1 × 2⁻¹) + (0 × 2⁻²) + (1 × 2⁻³)

= 0.5 + 0 + 0.125

= 0.625₁₀

Decimal Fraction to Binary

To convert a decimal fraction to binary, repeatedly multiply the fractional part by 2. Record the integer part of each result in order.

Example: Convert 0.625₁₀ to binary.

0.625 × 2 = 1.25  → 1
0.25  × 2 = 0.50  → 0
0.50  × 2 = 1.00  → 1

Answer: 0.101₂

Overflow

Overflow occurs when the result of a calculation exceeds the range that can be represented using a fixed number of bits.

A computer system has a limited number of bits available for storing a value. If the result is outside the supported range, overflow may occur.

Example of Unsigned Overflow

An 8-bit unsigned integer can store values from 0 to 255. Adding 1 to 255 produces a mathematical result of 256, which cannot be represented in 8 bits. 

  11111111  = 255
+ 00000001  =   1
-----------
1 00000000  = 256

The extra carry is outside the 8-bit result.

Causes of Overflow

  • Adding values that exceed the available range.
  • Using a data type that is too small for the result.
  • Performing calculations with very large values.

Why Overflow Matters

Overflow can produce incorrect results in software calculations. It is important in financial systems, scientific applications, and other programs that require accurate numerical processing.

Floating-Point Representation

Floating-point representation is a method used by computers to store real numbers, including numbers with fractional parts and very large or very small values.

It represents numbers using a sign, exponent, and significand (also called the fraction or mantissa in many introductory explanations).

Scientific Notation

Scientific notation expresses a number as a value multiplied by a power of a base. In decimal scientific notation, the base is 10.

Example:

125000 = 1.25 × 10⁵

Binary floating-point uses a similar idea, but represents values using powers of two.

IEEE 754 Single Precision

IEEE 754 is a widely used standard for representing floating-point numbers. Its single-precision format uses 32 bits.

Component Number of Bits Purpose
Sign 1 Indicates positive or negative.
Exponent 8 Stores the exponent using a biased representation.
Fraction 23 Stores the fraction portion of the value.

Floating-Point Limitations

  • Some decimal fractions cannot be represented exactly in binary.
  • Calculations may produce rounded results.
  • Limited precision can affect calculation accuracy.
  • Overflow and underflow may occur when values exceed the supported range.

Applications of Floating-Point Numbers

  • Scientific calculations
  • Weather forecasting
  • Computer graphics
  • Engineering calculations
  • Statistical applications

Binary Coded Decimal (BCD)

Binary Coded Decimal, commonly known as BCD, is a method of representing decimal digits using groups of four binary bits.

In BCD, each decimal digit is represented separately by its corresponding 4-bit binary value.

BCD Conversion Table

BCD Example

Convert 25 into BCD.

2 = 0010
5 = 0101

25 = 0010 0101

Each decimal digit is converted separately. Therefore, BCD representation is different from converting the entire number directly into ordinary binary.

Applications of BCD

  • Digital clocks
  • Calculators
  • Digital displays
  • Electronic measuring devices

Advantages of BCD

  • Easy conversion between decimal digits and BCD.
  • Useful for displaying decimal values.
  • Can simplify certain decimal-based applications.

Limitations of BCD

  • Uses more bits than ordinary binary for many values.
  • Not all possible 4-bit combinations represent valid decimal digits.
  • Arithmetic operations can require additional processing.

Boolean Representation

Boolean representation is used to represent logical values. It has only two possible states: TRUE and FALSE.

In digital systems, Boolean values are commonly associated with binary values:

  • TRUE = 1
  • FALSE = 0

Data Types

A data type identifies the kind of value that a variable can store. It helps a programming language determine how data should be handled and what operations can be performed.

Common Data Types

Data Type Description Example
Integer Stores whole numbers. 25
Float Stores numbers with fractional values. 3.14
Double Stores floating-point values with greater precision than a typical float. 125.6789
Character Stores a single character. 'A'
String Stores a sequence of characters. "Hello"
Boolean Stores TRUE or FALSE. TRUE

Examples in Programming

// Character
char grade = 'A';

// Integer
int age = 20;

// Floating-point
float temperature = 36.5;

// Boolean
bool isEnrolled = true;

// String
string studentName = "Alex";

The exact names, sizes, and supported ranges of data types depend on the programming language and the system being used.

Selecting Appropriate Data Types

Selecting the appropriate data type is important when developing computer programs. The selected data type affects how information is stored, processed, and interpreted.

Factors to Consider

  • Type of information: Determine whether the value is a number, character, text, or logical value.
  • Range of values: Consider the minimum and maximum values that must be stored.
  • Precision: Determine whether decimal accuracy is required.
  • Memory usage: Consider how much memory the selected data type requires.
  • Operations: Choose a type that supports the calculations or comparisons needed by the program.

Examples of Data Type Selection

Information Suggested Data Type Reason
Student age Integer Usually stored as a whole number.
Student name String Contains multiple characters.
Subject grade Float or Double May contain decimal values.
Enrollment status Boolean Can be TRUE or FALSE.
Section code String May contain letters and numbers.

Practical Applications

Number systems and data representation are used in almost every area of computing. They allow computer systems to store, process, and exchange information.

Computer Programming

Programmers use number systems and data types to store values, perform calculations, and create logical conditions in applications.

Database Management

Databases use data types to organize and store information such as names, ages, addresses, dates, and numerical records.

Digital Communication

Digital communication systems convert information into binary data so that it can be transmitted between computers and other electronic devices.

Computer Graphics

Digital images are represented using numerical values. These values describe pixel colors, brightness, and other image properties.

Audio and Video Processing

Audio and video systems convert signals into digital data. Computers process this information to record, edit, store, and play multimedia files.

Cybersecurity

Binary representation and data encoding are important in computer security, data processing, encryption systems, and digital communication.

Key Takeaways

  • Data representation explains how computers store and process information.
  • A bit is the smallest unit of digital information, while a byte contains eight bits.
  • Computers primarily use binary because electronic circuits can represent two states.
  • Binary, decimal, octal, and hexadecimal are important number systems in computing.
  • Number system conversion changes the representation of a value without changing its actual quantity.
  • ASCII, EBCDIC, and Unicode are character encoding standards.
  • Signed and unsigned integers have different numerical ranges.
  • Two's complement is commonly used to represent signed integers.
  • Binary arithmetic includes addition, subtraction, multiplication, and division.
  • Floating-point representation is used for numbers containing fractional values.
  • BCD represents each decimal digit using four binary bits.
  • Boolean representation uses TRUE and FALSE logical values.
  • Choosing the correct data type helps programs store and process information properly.
