Overview of Computer Architecture

Computer architecture is the study of how computers are designed, organized, and operated. It explains how hardware and software work together to process information, execute instructions, store data, and produce results.

Modern computers are used in almost every part of daily life. They are found in desktop computers, laptops, smartphones, tablets, televisions, gaming devices, and many other electronic products. Although these devices may perform different tasks, they all use computing systems to process information.

Computer architecture examines the basic technologies, instructions, components, and design principles that allow computers to function efficiently. Understanding these concepts helps students learn how computer systems work internally and how software communicates with hardware.

What Is a Computer?

A computer is a programmable electronic device that receives information, processes data according to instructions, stores information, and produces meaningful results.

Computers do not independently understand every task. They follow programs created by people. These programs provide instructions that tell the computer what operations to perform.

Basic Parts of a Computer System

  • Computer: The device that performs operations and processes information.
  • Program: A collection of instructions that tells the computer what to do.
  • Information Store: The data, numbers, text, and other information used by a program.
  • Results: The output produced after the computer processes the information.

Example of Computer Processing

Consider a simple program that adds two numbers. The computer follows the instructions, performs the calculation, and displays the answer. 

a = 4;
b = 6;
c = a + b;
print(c);

The computer stores the values of the variables, adds the two numbers, and displays 10 as the result.

Structure of a Typical Computer

A typical desktop computer contains several major components that work together to execute programs and process information. The most important components include the Central Processing Unit, main memory, and permanent storage.

Central Processing Unit (CPU)

The CPU is the main processing component of a computer. It executes program instructions, performs calculations, makes logical decisions, and coordinates the activities of other computer components.

It is commonly called the brain of the computer because it controls the execution of instructions.

Main Memory

Main memory temporarily stores programs and data that the CPU needs while performing tasks. It allows the processor to access working information during program execution.

In ordinary computers, main memory such as RAM is volatile. Its stored information is lost when the computer is powered off.

Hard Disk and Permanent Storage

Permanent storage keeps programs, documents, images, videos, and other files even when the computer is turned off. Examples include hard disk drives, solid-state drives, and external storage devices.

Input and Output Devices

Input and output devices allow users to communicate with a computer and receive information from it.

  • Keyboard: Used to enter text, numbers, and commands.
  • Mouse: Used to control the pointer and select items on the screen.
  • Monitor: Displays text, images, videos, and program results.
  • Printer: Produces printed copies of digital documents and images.

Computers as Instruction-Following Machines

Computers are powerful because they can execute simple instructions extremely quickly and repeatedly. However, they do not naturally possess human creativity, judgment, or independent understanding.

A computer follows the instructions contained in a program. The programmer uses logical thinking and problem-solving skills to create instructions that the computer can execute.

When human-designed programs are combined with the processing speed of computers, they can perform complex tasks such as managing information, creating documents, communicating, analyzing data, and running applications.

Why Programs Are Important

A program provides a clear sequence of instructions. Without instructions, a computer cannot know what task it is expected to perform. Programs make computers useful for different purposes, even when the hardware is similar.

The Language of Computer Instructions

Computers operate using basic instructions that their processors are designed to understand. Human programmers usually write programs using high-level programming languages such as C, C++, Java, and other languages.

High-level languages are easier for people to read and write. However, their statements must be translated into machine-level instructions before a processor can execute them.

Compiler

A compiler is a software program that translates source code written in a programming language into machine code or another executable form. It allows programmers to focus on solving problems instead of manually writing every machine instruction.

Write, Compile, and Execute

The general process begins when a programmer writes a program. The compiler translates the source code into an executable program. The computer then executes the instructions and produces the expected output.

Instruction Set

An instruction set is the collection of basic commands supported by a processor. These commands tell the CPU what operations it can perform.

Common instruction examples include:

  • ADD: Adds two values.
  • SUBTRACT: Subtracts one value from another.
  • MULTIPLY: Multiplies values.
  • DIVIDE: Divides one value by another.
  • AND / OR: Performs logical operations.
  • NOT: Reverses a logical value.

Instruction Set Architecture (ISA)

Instruction Set Architecture, or ISA, defines the instructions a processor supports and how software uses them. It describes the operations, operands, registers, and interfaces that software can use to communicate with the processor.

The ISA acts as an interface between software and hardware. Different processor families may use different instruction sets, such as x86 and ARM. A program compiled for one processor architecture may not run directly on another architecture without suitable translation or compatibility support.

Instruction Set Design

Instruction set design involves selecting the commands that a processor must support. The instruction set must allow software to perform its required tasks while remaining practical for hardware to implement.

Completeness

An instruction set should be capable of expressing all programs intended for its processor. It needs instructions for calculations, decisions, and repeated operations.

For example, a processor that only supports addition cannot directly perform every required operation. It also needs a way to implement subtraction, comparisons, and program control.

Conciseness

An instruction set should avoid unnecessary instructions. Every additional instruction may require extra hardware and increase processor complexity. A carefully designed instruction set balances functionality and simplicity.

Generic Instructions

Instructions should support common operations used by many programs. Arithmetic and logical instructions are important because they are frequently needed in everyday computing.

Simplicity

Instructions should be practical to understand, decode, and implement in hardware. Simpler instruction designs can help reduce the complexity of the processor.

Universal Machines and Turing Machines

A universal machine is a theoretical computing machine capable of executing any program that can be represented in its instruction system. The idea of universal machines helps computer scientists understand the capabilities and limitations of computation.

Alan Turing introduced the Turing machine as a theoretical model of computation. It provides a simple way to describe how a machine reads information, changes symbols, follows instructions, and moves through a sequence of operations.

Parts of a Turing Machine

  • Infinite Tape: A theoretical storage area divided into cells that contain symbols.
  • Tape Head: Reads and writes symbols on the tape and moves left or right.
  • State Register: Stores the current state of the machine.
  • Action Table: Contains the rules that determine what the machine does next.

How a Turing Machine Works

The machine reads the symbol in the current tape cell and checks its current state. It then consults the action table to determine which symbol to write, which state to enter, and whether the tape head should move left or right.

By repeatedly following these rules, a Turing machine can perform calculations and solve computational problems.

Examples of Turing Machine Applications

The theoretical model can describe different computational tasks, including incrementing a number, checking whether a string is a palindrome, and processing mathematical calculations.

Universal Turing Machine

A Universal Turing Machine is a Turing machine that can simulate another Turing machine. Instead of being designed for only one specific task, it can read the description of another machine and imitate its operations.

Church-Turing Thesis

The Church-Turing thesis states that any function that can be computed by an effective algorithm can be computed by a Turing machine. It is an important idea in theoretical computer science because it provides a common model for understanding computation.

Turing Completeness

A computing system is called Turing complete when it can perform the same general class of computations as a universal Turing machine, assuming sufficient memory and execution time.

Modified Universal Turing Machine

A modified universal Turing machine provides a more practical way to understand how modern computer systems organize instructions and data.

Instead of using only the basic theoretical tape model, it organizes its information into areas that represent instructions, the current state, and working data.

Main Components

  • Instruction Table: Contains the operations or instructions that the machine must execute.
  • Program Counter: Keeps track of the current instruction and identifies the next instruction to execute.
  • Memory: Stores instructions, variables, constants, and other information needed by a program.
  • Control Unit: Coordinates instruction execution and directs the operations of the processor.
  • Arithmetic Logic Unit: Performs arithmetic calculations and logical operations.

Basic Instruction Processing

A processor follows a sequence of operations when executing a program. It obtains the next instruction, interprets it, performs the required operation, and continues to the following instruction unless a branch or other control instruction changes the execution sequence.

Types of Instruction Set Operations

Single-Instruction ISA

A single-instruction instruction set architecture uses only one basic instruction to perform different computations. One example is the SBN instruction, which means subtract and branch if negative.

The SBN instruction subtracts the value in one memory location from another, stores the result, and changes the program flow if the result is negative. Although theoretically powerful, writing programs with only one instruction is difficult and can produce long programs.

Multiple-Instruction ISA

A multiple-instruction ISA provides different instructions for common operations. This makes programs easier to write, understand, and execute.

Major Categories of Instructions

  • Arithmetic Instructions: Perform calculations such as addition, subtraction, multiplication, and division.
  • Data Transfer Instructions: Move information between registers and memory or load values into storage locations.
  • Branch Instructions: Change the normal execution sequence based on a condition or a program instruction.

Design of Practical Computer Architectures

Theoretical computing models help computer scientists understand how computation works. Practical computer architectures apply these ideas to build real machines that can efficiently execute programs.

Harvard Architecture

Harvard architecture uses separate memory systems for instructions and data. It also provides separate paths for accessing these two types of information.

Because instructions and data are stored separately, the processor can access them through their respective memory systems. This organization can improve performance in systems that benefit from simultaneous instruction and data access.

Main Components of Harvard Architecture

  • Instruction Memory: Stores the program instructions.
  • Data Memory: Stores the information used by the program.
  • Control Unit: Coordinates the execution of instructions.
  • Arithmetic Logic Unit: Performs arithmetic and logical operations.
  • I/O Devices: Allow the system to receive input and provide output.

Von Neumann Architecture

Von Neumann architecture uses a shared memory system to store both program instructions and data. The CPU retrieves instructions from memory, interprets them, and performs the required operations.

Its important feature is the stored-program concept. Instructions are encoded and stored in memory just like other data values. This allows programs to be stored, modified, and executed using a common memory system.

Stored-Program Concept

The stored-program concept means that program instructions are stored in memory and treated as encoded memory values. This approach simplifies computer design and allows instructions and data to share the same memory system.

Harvard and Von Neumann Architecture Compared

Feature Harvard Architecture Von Neumann Architecture
Memory Separate instruction and data memory Shared instruction and data memory
Data Access Separate memory paths Shared memory path
Organization Separate storage systems Unified storage system
Common Use Some microcontrollers and digital signal processors General-purpose computer designs

Modern Machines with Registers

Modern processors commonly use registers to store values that are needed immediately during instruction execution. A register is a small, high-speed storage location inside the processor.

Main memory can store a large amount of information, but accessing it is generally slower than accessing processor registers. Registers help reduce repeated memory access and improve processing performance.

How Registers Work

The processor loads required values from memory into registers. It then performs calculations using those values and stores the results in registers or sends them back to memory.

For example, when a program adds two numbers, the processor can load the values into registers, perform the addition, and store the result.

Register-Based Processing Example

r1 = mem[a];
r2 = mem[b];
r3 = r1 + r2;
mem[c] = r3;

In this example, the computer loads two values from memory, adds them using registers, and stores the answer back in memory.

Von Neumann Machine with a Hardware Stack

A stack is a data structure that follows the Last In, First Out (LIFO) principle. This means the last value added to the stack is the first value removed.

A stack-based computer uses a hardware stack to store operands during calculations. Arithmetic instructions usually operate on the values at the top of the stack.

Basic Stack Operations

  • Push: Adds a value to the top of the stack.
  • Pop: Removes a value from the top of the stack.

Example of Stack Processing

Suppose a program needs to add two values. It pushes both values onto the stack, performs the addition, and replaces the operands with the calculated result. 

push 1;
push 2;
add;
pop result;

The stack stores the values temporarily and allows the processor to perform operations without explicitly identifying every operand in the arithmetic instruction.

Advantages and Limitations

Stack-based machines can produce compact instructions because many operations use values already stored at the top of the stack. However, managing complex expressions can require additional push and pop operations.

Accumulator-Based Machines

An accumulator-based machine uses a special register called an accumulator to store operands and calculation results.

When an arithmetic instruction is executed, the processor combines the value in the accumulator with another value from memory. The result is then stored back in the accumulator.

Example

LOAD A;
ADD B;
STORE C;

The processor loads a value into the accumulator, adds another value, and saves the final result to memory. This organization was common in early computers and influenced features in later processor designs.

Representing Information in Computers

Computers store and process information using binary values. Their electronic components represent information through two basic states, commonly represented as zero and one.

Numbers, text, images, instructions, and programs must all be encoded into combinations of binary digits before they can be processed by a computer.

Binary Digits

A bit is the smallest basic unit of digital information. It can represent one of two values: zero or one.

Byte

A byte is a group of eight bits. It is commonly used as a basic unit for measuring computer memory and file sizes.

Word

A word is a group of bits that a processor handles as a unit. Its size depends on the processor architecture. Some systems use 32-bit words, while others use 64-bit words.

Applications of Computer Architecture

Computer architecture is important in designing and improving the computer systems used in everyday life. Its principles help hardware and software developers build systems that are reliable, efficient, and capable of handling different workloads.

  • Personal Computing: Supports desktop computers and laptops used for school, work, and entertainment.
  • Mobile Devices: Provides the processing foundation for smartphones and tablets.
  • Business Systems: Supports databases, financial applications, office systems, and business information processing.
  • Scientific Computing: Helps process complex calculations, simulations, and research data.
  • Embedded Systems: Powers electronic devices such as appliances, vehicles, and automated equipment.
  • Networking and Communication: Supports devices that exchange information through computer networks.

Key Takeaways

  • Computer architecture explains how hardware and software work together to process information.
  • A computer follows program instructions to receive, process, store, and produce information.
  • The CPU, main memory, storage, and input/output devices are important parts of a computer system.
  • A compiler translates high-level programs into instructions that a computer can execute.
  • An Instruction Set Architecture defines the instructions supported by a processor.
  • Turing machines provide a theoretical model for understanding computation.
  • Harvard and Von Neumann architectures are two important computer organization models.
  • Registers, stacks, and accumulators are different ways processors organize temporary data and operands.
  • Computers represent information using binary values, including bits and bytes.

Practical Example: What Happens When You Run a Program?

When a student opens a calculator application and adds two numbers, several computer architecture components work together.

  • The user enters numbers using an input device such as a keyboard.
  • The program instructions and required data are made available in memory.
  • The CPU retrieves and executes the instructions.
  • The ALU performs the addition operation.
  • The result is stored temporarily and sent to the display system.
  • The monitor displays the final answer to the user.

This example demonstrates how software, memory, processing components, and output devices work together to complete a simple computing task.
